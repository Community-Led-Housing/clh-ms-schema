# CLH Metadata Schema (CLH-MS)

This repository hosts the versioned core and extension metadata schemas for Community-Led Housing (CLH) Data Pods.

Canonical schema URIs follow the format:

```
https://schema.community-led-housing.org/clh-ms/core/v0.1.yaml
```

Schemas are intended for use in:

- Data validation
- Linked open data publishing
- Cooperative profiling and data sharing

For documentation and examples, see the companion project:
[Community-Led-Housing/clh-data-pods](https://github.com/Community-Led-Housing/clh-data-pods)
